SecretoBoot V9 final-polish artwork provenance

The SecretoBoot branding, selectors, Windows-style four-pane icon,
Android/Bliss robot icon, Linux penguin-inspired icon, reboot icon, and
shutdown icon were created specifically for SecretoBoot V9 from original
vector geometry. No third-party icon pack is used by these runtime assets.

FinalRelease.1 composes the SecretoBoot shield, title, approved developer
credit (Mohamed LALAH / SecretoTools), and secretotools.com footer from
repository-owned HTML/SVG geometry. The user-supplied approved visual mockup
was used as a layout and styling reference; it is not redistributed as a
runtime asset.

The abstract dark-navy background base was generated with OpenAI's built-in
image generation tool from an original prompt requesting a minimal premium
boot-menu backdrop with a soft blue central glow, subtle glassy arcs, no text,
no logos, no icons, and no watermark. SecretoBoot branding was subsequently
composited locally from original vector/HTML source.

Development sources are retained under v9/theme-src/SecretoBootV9.
The upstream notices in this directory apply to bundled rEFInd, not to the
original SecretoBoot artwork described above.

FinalRelease.2 (Obsidian Nova refresh) replaces the background, branding,
selectors, OS icons, and function icons with new original artwork: all icons,
selectors, and branding were drawn programmatically from original vector
geometry (supersampled Python/Pillow builds), and the abstract background base
was generated with an AI image tool from an original prompt, then
post-processed by repository-owned code (darkening, vignette, and a baked
wordmark/subtitle rendered from repository geometry). No third-party icon
pack is introduced; filenames, dimensions, and the deployment layout are
unchanged from FinalRelease.1.

FinalRelease.3 (LATCHI BOOT MENU edition) rebrands the visible boot-screen
identity to "LATCHI BOOT MENU" per client request: the background wordmark
and branding plate are re-rendered from repository-owned geometry, the android.png and bliss.png slots (auto-plan and manual-confirmation paths both map Android-family entries to bliss.png) become identical Android TV emblems (robot head on a TV set, original vector geometry), the linux slot becomes a Chromium-style segmented-ring
emblem for the client's FydeOS installation (original geometry, no
third-party logo), and icon/selector glows were intensified. The background
base including the RGB edge lighting and the client-approved mascot
character (holding Windows and Android TV emblems) was generated with an AI
image tool from an original prompt; the mascot likeness follows the client's
approved master character sheet. No third-party icon pack is introduced;
filenames, dimensions, and the deployment layout are unchanged.
